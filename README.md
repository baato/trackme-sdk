# TrackMe

A Kotlin Multiplatform (KMP) SDK that produces **Android** and **iOS** packages, plus **Flutter** and **React Native** packages that wrap them, so any host app can:

- share live location with one another,
- form groups (trips), and
- join a group via a shareable link / join code.

The project doubles as a step-by-step KMP walkthrough:

1. [docs/01-kmp-setup.md](docs/01-kmp-setup.md): KMP build setup
2. [docs/02-sdk-design.md](docs/02-sdk-design.md): public API contract and roadmap
3. [docs/03-location-sharing.md](docs/03-location-sharing.md): location permission and the sharing engine
4. **[docs/04-integration-guide.md](docs/04-integration-guide.md): how an app integrates the SDK (Android + iOS)**
5. [docs/05-releasing.md](docs/05-releasing.md): publishing to Maven and SwiftPM
6. [docs/06-sample-apps.md](docs/06-sample-apps.md): which sample screen calls which SDK function, and a two-device test script
7. [docs/07-ports.md](docs/07-ports.md): the Flutter and React Native packages (one JSON bridge over the native SDK)

## Repository layout

| Path | What |
|---|---|
| `trackme-sdk/` | the KMP library → Android AAR + `TrackMeSDK.xcframework` |
| `sample-android/` | Compose demo: Live map showcase (MapLibre + Baato) and developer screens covering every SDK call (`./gradlew :sample-android:installDebug`) |
| `TrackMeLiveActivity/` | Swift package: iOS lock screen / Dynamic Island Live Activity + iOS 15 notification fallback |
| `sample-ios/` | SwiftUI demo: the same Live map and developer screens, plus the Live Activity widget (XcodeGen; see its README) |
| `examples/` | the same two apps built against the **published** SDK (JitPack / SwiftPM), like a customer app; see its README |
| `flutter/trackme_flutter/` | Flutter plugin over the native SDK; `example/` is the Live map + developer screen |
| `react-native/trackme-react-native/` | React Native Turbo Module (+ Expo config plugin) over the native SDK; `example/` likewise |
| `Package.swift` | SwiftPM manifest for releases, generated by `scripts/release-ios.sh` |
| `scripts/release-ios.sh` | builds and zips the XCFramework, generates the SwiftPM `Package.swift` |
| `scripts/sync-examples.sh` | copies the sample app code into `examples/` |
| `scripts/port-ios-sdk.sh` | puts the iOS SDK (local build or a release) and the lock-screen code into the Flutter / React Native packages |
| `scripts/ios-add-widget-extension.rb` | adds the Live Activity Widget Extension to any iOS app project |
| `scripts/check-aar-metadata.sh` | prints the compileSdk each OkHttp release asks of apps |

## Install (0.3.1)

**Android** (JitPack):

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google(); mavenCentral()
        maven("https://jitpack.io") { content { includeGroup("com.github.baato.trackme-sdk") } }
    }
}
// app/build.gradle.kts  (compileSdk 36+, minSdk 24 (Android Gradle Plugin 8.11+ recommended; older 8.x builds with a warning))
dependencies { implementation("com.github.baato.trackme-sdk:trackme-sdk-android:0.3.1") }
```

**iOS** (SwiftPM): *File → Add Package Dependencies…* → `https://github.com/baato/trackme-sdk` → `0.3.1`, then add `TrackMeSDK` (and `TrackMeLiveActivity` for the Live Activity) to your app.

**Flutter** (git; pub.dev only takes open-source licences):

```yaml
trackme_flutter:
  git: { url: https://github.com/baato/trackme-sdk.git, path: flutter/trackme_flutter, ref: 0.3.1 }
```

**React Native** (0.76+, new architecture; Expo development builds too): `npm install @baato/trackme-react-native`

Both download the matching iOS framework on the first `pod install` and show sharing on the iOS lock screen with no app code. Setup: [flutter/trackme_flutter/README.md](flutter/trackme_flutter/README.md), [react-native/trackme-react-native/README.md](react-native/trackme-react-native/README.md).

Full guide: [docs/04-integration-guide.md](docs/04-integration-guide.md). Working apps: [examples/](examples/).

## Quick start (developing the SDK)

```bash
./gradlew :trackme-sdk:allTests                      # tests on Android JVM + iOS simulator
./gradlew :trackme-sdk:assembleTrackMeSDKXCFramework  # → trackme-sdk/build/XCFrameworks/
./gradlew :trackme-sdk:publishToMavenLocal           # → ~/.m2 (io.baato.trackme:trackme-sdk-android, local testing)
./gradlew :sample-android:installDebug               # demo app on a connected device / emulator
cd sample-ios && xcodegen && open TrackMeSample.xcodeproj   # iOS demo app
```

Samples need secrets in git-ignored files (TrackMe demo secret, Baato map key) and have a dev-tools flag: see [docs/06-sample-apps.md](docs/06-sample-apps.md#setup-secrets-and-the-dev-tools-flag).
